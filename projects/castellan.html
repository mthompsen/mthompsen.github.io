  • NIST SP 800-53 / RMF compliance toolkit: describe a system in YAML, get FIPS-199 categorization, an SP 800-53B baseline, a System Security Plan, a read-only Linux hardening scan, and a control-by-control report.
  • Emits OSCAL SSP, POA&M, and assessment-results JSON plus human-readable Markdown; 20 read-only host checks mapped to controls through a hand-curated table modeled on DISA CCI.
  • "Never auto-pass" design: on a real Ubuntu host run against a moderate baseline (287 controls), it reports 11 technically assessable controls rather than inflating results.
  • 208 tests at 97% coverage. Companion blog post: "Map and Fortress: Why I Built Castellan."
